# متحكم الأداء (PerfControl)

تطبيق أندرويد للتحكم في أداء الجهاز عبر Shizuku، مصمم لجهاز Poco F5 Pro (أندرويد 15).

## الحصول على ملف APK (مجاناً عبر GitHub)

1. أنشئ مستودعاً جديداً على github.com (زر **New repository**) واجعله **Public**.
2. افتح المستودع واضغط **uploading an existing file**.
3. فُكّ ضغط هذا المشروع، وحدّد **كل** محتوى المجلد (بما فيه المجلد `.github`) واسحبه إلى الصفحة.
4. اضغط **Commit changes**.
5. افتح تبويب **Actions**. سيبدأ البناء تلقائياً (5 إلى 10 دقائق).
6. حين يظهر علامة ✔ الخضراء اضغط على اسم التشغيل، وانزل إلى **Artifacts**، ونزّل **PerfControl-APK**.
7. فُكّ ضغط الملف، وانقل ملف `.apk` إلى هاتفك وثبّته (فعّل "التثبيت من مصادر غير معروفة").

إن لم يظهر شيء في تبويب Actions، فالمجلد `.github` لم يُرفع. أنشئه يدوياً:
**Add file ← Create new file**، اكتب الاسم `.github/workflows/build.yml`، والصق محتوى الملف الموجود في هذا المشروع بنفس المسار.

إن فشل البناء (علامة ✘ حمراء) فانسخ نص الخطأ وأرسله للمطوّر.

## إعداد Shizuku على شاومي

1. ثبّت Shizuku وفعّل خيارات المطوّر.
2. فعّل **التصحيح اللاسلكي** وشغّل Shizuku من خلاله.
3. في خيارات المطوّر فعّل أيضاً **تصحيح USB (إعدادات الأمان)**.
4. افتح التطبيق، واضغط **إعداد** ثم **طلب الإذن**.

بعد كل إعادة تشغيل للجهاز يلزم تشغيل Shizuku من جديد.

## أول تشغيل

افتح **الإعدادات ← فحص التوافق** واضغط **تشغيل الفحص**. أرسل النتيجة للمطوّر ليصلح ما لا يعمل على جهازك.

## للمطوّرين

- فتح المشروع: Android Studio (يزامن Gradle تلقائياً)، أو `gradle assembleDebug`.
- اختبارات المنطق: `gradle :core:test`.
- المواصفات: `docs/superpowers/specs/`، والخطة: `docs/superpowers/plans/`.
